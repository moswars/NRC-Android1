# تطبيق NRC للأندرويد

هذا مشروع Android Studio يفتح نظام تأجير السيارات المنشور على Google Apps Script داخل تطبيق WebView، مع شاشة افتتاحية وأيقونة NRC.

## بناء APK مجاناً عبر GitHub

1. فك ضغط ملف ZIP.
2. أنشئ مستودعاً جديداً في GitHub وارفع محتويات المجلد إليه على الفرع `main`.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build NRC APK** ثم اضغط **Run workflow** (أو انتظر البناء التلقائي بعد رفع الملفات).
5. بعد نجاح البناء افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. نزّل `NRC-Android-APK.zip` واستخرج منه `app-debug.apk`.
7. انقل APK إلى هاتف Android وثبّته. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

## ملاحظات مهمة

- التطبيق يحتاج اتصال إنترنت.
- بيانات السيارات والعملاء تبقى في Google Sheets؛ التطبيق لا ينشئ قاعدة بيانات منفصلة.
- لا تغيّر إعدادات `APP_PASSWORD` أو كلمات مرور النظام.
- تأكد أن نشر Apps Script يسمح للمستخدمين المقصودين بفتح التطبيق. لا تجعل البيانات عامة لمجرد حل مشكلة دخول؛ راجع صلاحيات النشر بعناية.
- هذا إصدار تجريبي غير منشور على Google Play، وAPK من GitHub Actions سيكون نسخة Debug.
- تسجيل الدخول بحساب Google داخل WebView قد تمنعه Google في بعض الحالات. الأفضل أن يفتح نشر Apps Script مباشرة مع تسجيل الدخول الداخلي للتطبيق، وأن يكون الوصول مضبوطاً وفق احتياجك.
